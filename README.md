# DOTDVN Portfolio

This is my personal portfolio website. I made it to have a place where I can introduce myself, share what I build, and improve my frontend development skills.

## About

I'm Devanarayanan from Kerala. I enjoy working on IoT, embedded systems, and web development. This website is my first step towards building my online portfolio.

## Features

- Modern and minimal design
- Responsive layout
- About Me section
- Social media links
- Simple animations
- Built using only HTML, CSS, and a little JavaScript

## Why I Built This

I wanted a portfolio that matches my style instead of using a template. I focused on keeping the design clean while learning more about layouts, animations, and responsive design.

## Challenges

The hardest part was getting the spacing and layout right on different screen sizes. I also spent time adjusting the typography and animations until everything looked the way I wanted.

## What I Learned

- Better HTML structure
- CSS Grid and Flexbox
- Responsive design
- CSS animations and transitions
- Organizing a small web project

## Built With

- HTML
- CSS
- JavaScript

## AI Usage

I used AI as a development assistant during this project. It helped me:

- Test parts of my code and find bugs.
- Add interactive elements and simple animations.
- Get suggestions for improving the UI and user experience.
- Debug HTML, CSS, and JavaScript issues.

The website's design, layout, styling, customization, and implementation were created and modified by me. AI was only used to assist with testing, debugging, and enhancing interactivity.
